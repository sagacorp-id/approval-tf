# Form Approval TF — Internasional Komputer

Aplikasi web (PWA) untuk pengajuan transfer ke manager: pesan WhatsApp siap kirim, riwayat, rekap bulanan per supplier, dan buku rekening.

- Bisa dipasang di laptop (Chrome/Edge: **Instal aplikasi**), Android (**Tambahkan ke layar utama**) dan iPhone (Safari → Bagikan → **Tambah ke Layar Utama**).
- Data tersimpan di Google Sheet milik toko lewat Google Apps Script (`apps-script/Code.gs`), dilindungi PIN.
- Baca foto invoice memakai Gemini API (key disimpan di Script properties, tidak ada di repo ini).

Repo ini tidak berisi data, PIN, maupun API key.
